## 기능별 확인

- 단어장·단어 생성·이름/뜻/품사/허용 정답 편집·삭제를 HTTP와 SQLite 조회로 확인했습니다.
- 직접 입력, TAB 일괄 입력, SQLite 사전 후보 선택, 조회 없는 단어의 직접 뜻 입력을 브라우저에서 실행했습니다. 쉼표 보존, 공백·대소문자 중복 제외, 같은 철자의 서로 다른 의미를 확인했습니다.
- 저장 상태의 중복 요청, 중요·잊음 동시 선택, 필터, 검색, 저장 해제를 확인했습니다. 단어장 삭제 후 저장 카드 유지와 카드 자체 삭제 후 저장 제거도 확인했습니다.
- **실제 uvicorn 프로세스를 종료하고 새 프로세스로 다시 실행**한 테스트에서 저장 카드, 학습 순서·위치·뒤집기 상태, 시험 답안·문항 위치가 유지됐습니다. 브라우저 새로고침 복원도 별도로 통과했습니다.
- 빈 단어장 출제 거절, 요청한 개수보다 적은 카드의 안내, 한 세션 내 카드 ID 중복 방지를 확인했습니다.
- 개인 단어장과 선택 레벨의 시험을 브라우저에서 시작했습니다. 제출 전 응답은 정답/허용 정답 필드를 포함하지 않았고 시험 화면에는 발음 버튼이 없었습니다.
- 대소문자·앞뒤 및 연속 공백 정규화, 등록된 허용 정답, 미등록 동의어의 오답 처리를 확인했습니다. 같은 시험의 동시 제출 두 요청이 하나의 결과를 반환하고 완료 시험 횟수가 한 번만 늘어났습니다.
- 오답만 재시험, 오답 카드 학습, 오답 잊음 일괄 저장을 확인했습니다. 시험 시작 당시의 카드 내용으로 채점하는 것도 확인했습니다.
- 총점 0·3→L1, 4·6→L2, 7·10→L3와 모든 Zipf 경계를 검사했습니다. AI 점수의 범위 초과·음수·실수·boolean을 거절하며 실패 기록에 잘못된 점수를 저장하지 않았습니다. Zipf 0은 레벨을 확정하지 않습니다.
- AI JSON 검증, 완료 결과 재사용, 실패 재처리, 검수 전 비공개와 검수 후 공개는 **모의 Ollama 응답으로 검증**했습니다. 테스트에서 생성한 결과는 임시 DB 밖으로 저장하지 않았습니다.
- WordNet 재수집과 시연 시드 재실행이 사용자 자료와 사전 ID·개인 카드 연결을 유지했습니다. 활용형 dogs를 dog 표제어로 수집하는 것도 확인했습니다.
- WordNet·AI·발음 미지원 상태에서도 직접 등록, 학습, 시험이 작동했습니다. 서버 연결 실패 시 한국어 오류를 표시하고 저장 버튼 상태를 성공으로 바꾸지 않았습니다.
- 1440px 데스크톱과 320·390·768px의 화면 너비에서 가로 넘침을 검사했습니다. 긴 단어를 가진 학습·시험 카드와 주요 버튼의 경계도 확인했습니다. 모바일은 실제 휴대폰이 아닌 Chromium 에뮬레이션입니다.
- 음성 목록의 지연 준비, 영어 음성 선택, 자동 재생 없음, 연속 클릭 시 이전 재생 취소는 **모의 브라우저 음성 API로 확인**했습니다. 실제 소리 출력은 확인하지 못했습니다.

## 확인하지 못한 범위와 운영 한계

- Ollama와 실제 로컬 모델은 이 환경에 없으므로 실제 모델 응답·평가 품질은 검증하지 않았습니다. 이미 설치된 모델을 연결한 후 평가·검수 명령으로 확인해야 합니다. 모델 자동 다운로드는 없습니다.
- Windows PowerShell 명령은 문서화했지만 Windows에서 실행하지 않았습니다. 모바일 Safari 및 실제 기기의 음성·레이아웃은 별도 확인이 필요합니다.
- 초기 검수는 CSV 내보내기와 CLI 승인/거절입니다. CSV 재가져오기, Zipf 0의 수동 빈도 편집 도구, 관리자 웹사이트는 없습니다.
- 대규모 사전 전수 수집, 로그인, 동기화, 공유 단어장, 자동 간격 반복은 구현하지 않았습니다. 서버 DB 하나를 쓰는 단일 사용자 앱입니다.
- 브라우저 다운로드 도메인은 환경 정책에 막혀 기존 `/usr/bin/chromium`으로 검증했습니다. 추가 네트워크 허용 없이 검증을 완료했고 불필요한 도메인 추가 초안은 제거했습니다.
- 클라우드의 `install_script`와 `start_skill` 초안을 저장했습니다. 초안 저장은 실행·게시가 아니며 새 작업의 스냅샷 복원은 검증하지 않았습니다. 환경 설정에서 검토·저장 후 Publish해야 이후 작업에 게시된 환경을 사용할 수 있습니다.

- 서버 모드와 브라우저 모드 모두 TypeScript 검사·Vite 빌드를 통과했습니다.

## 로컬 Ollama 평가·이동 워크플로

`local_evaluate run --limit 10`, `run --all`, `export`, `import`, `publish` 및 PowerShell 도우미를 추가했습니다. 실제 Ollama/사용자 PC 연결 없이 모의 HTTP 응답으로 검증했으며, 전체 백엔드 테스트 **64개가 통과**했습니다. 시험 평가 후 재개·다른 모델 구분·중단/실패 복구·SQLite 즉시 저장·중복/손상 결과 가져오기·개인 자료 보존·검수 상태 이동·Ollama 없는 게시를 확인했습니다. PowerShell 및 실제 로컬 모델의 품질/실행 속도는 Windows에서 실행 검증하지 않았습니다. 절차는 docs/LOCAL_OLLAMA.md에 있습니다.
